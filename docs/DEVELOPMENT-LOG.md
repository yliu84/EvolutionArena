## 产品基线（开工前）

- 类型：计划
- 玩家可见结果：浏览器单人动作肉鸽，猎杀 → 生物质/基因 → 进化 → 更危险区域 → Boss
- 原始规格：
  - Phaser 3 + TypeScript + Vite
  - 目标一局 12–15 分钟，16 分钟硬结束
  - 预算上限 CAD 500，验证窗口 8 周
  - 首发 CrazyGames Basic Launch，itch.io 为后备
  - 内容天花板：1 个模块化玩家、3 初始物种、12 突变、12 怪、3 Boss、5 精英词缀
  - 非目标：联机、账号、内购、写实 3D、开放世界
- 为什么：用小预算验证「猎杀塑造进化」是否好玩，而不是先做网游或完整美术
- 明确不做 / 后置：实时多人、服务器经济、局内强插广告
- 下一道门：当时尚未对照仓库做进度审核

## 2026-08-13 · 产品方向调整：无限进化与长局

- 类型：计划
- 玩家可见结果：尚未实现，只确定方向
- 做了什么：将「短局网页 Roguelite」调整为以猎杀物种和模块化身体为核心的单机探索肉鸽
  - 初版目标：6 次进化，约 25–35 分钟
  - 成熟版：10 次进化，约 35–45 分钟，不设强制结束时间
  - 猎杀 6 族对应 6 条基因：獠牙 / 翼族 / 甲壳 / 虫群 / 毒液 / 裂隙
  - 最近猎杀约 60%，本局累计约 40%；每次 3 选项；保底 + 1 次刷新
  - 模块化身体，不为每种组合画整图
  - 视觉体型最大约 1.58，碰撞最多约 +15%–20%
  - 第 6 次进化并集齐印记后，可立即打 Boss 或继续进化
  - 长局需要：中途存档、暂停、一次茧化重生、阶段性威胁变化
  - DNA / 永久档案后置
- 为什么：核心幻想是无限进化；短局硬上限不再匹配
- 评估结论（未整包开工）：
  - 方向对，但「下一步」不能同时做算法、外观、长局运营、30 分钟内容
  - 仓库里已经有 6 族和 12 条突变，缺的是接线，不是从 4 扩到 12
  - 当前地图撑不住 30 分钟；免费死亡会让「现在打 Boss 还是继续进化」变成假选择
  - 16 分钟硬上限可以取消；25–45 分钟是成熟版目标，不是下一周规格
- 明确不做 / 后置：DNA、第 7–10 次内容、中途存档、茧化、为凑时长而稀释节奏
- 下一道门：先做进化系统 v2，验收为三条猎杀路线长成三种不同终极生物

## 2026-08-13 · 决策：进化由猎杀决定，不由玩家选牌

- 类型：决策
- 玩家可见结果：玩家的选择发生在「打谁、吃谁」，而不是暂停后挑三张牌
- 做了什么：把构筑模型从「肉鸽三选一」改成「定向涌现」
  - 内部仍可用优势 / 组合 / 异变算法，但不弹窗让玩家挑
  - 生物质满时自动生长
  - 猎杀过程中显示倾向条和原因文案
  - 快定型时预告「身体正在向某族变化」
  - 每局一次「抗拒」，推迟这次生长并继续猎杀改倾向
  - 结算展示完整基因链
  - 好的不确定：你明显在长翅膀，但这次是疾风翼、毒翼还是融合
  - 坏的不确定：打了翼族却长出甲壳，或把倾向完全藏起来
- 为什么：
  - 核心幻想是「你吃什么就变成什么」
  - 三选一会让玩家忽略猎物，只在菜单里做决定
  - 以后若做玩家互吞，对战中无法暂停选牌；单机怪物应是同一套 `猎物基因 → 身体变化` 接口的教程
- 明确不做 / 后置：现在不做匹配、房间、同步；网游只当北极星
- 下一道门：按此模型实现进化 v2

## 2026-08-13 · 实现：进化系统 v2（猎杀自动生长）

- 类型：功能
- 玩家可见结果：
  - 界面从 Phase 2 Boss Hunt 改为 Phase 3 Hunt Evolution
  - 左下角六族倾向条 + 原因文案 + 当前形态 `n/6`
  - 生物质达到阶段阈值后约 2.2 秒自动进化，战斗不暂停
  - 按 R 或点击按钮可抗拒一次
  - 每次进化改变几何身体部件、体型、颜色/特效，并赋予真实战斗能力
  - 野外死亡结束本局并展示基因链；Boss 战仍可重试
  - 切到浏览器后台会暂停
  - 第 6 次进化且集齐三印后，可挑战 Boss，也可继续猎杀
- 做了什么：
  - `src/evolution.ts`：可配置阶段（默认 6，阈值表可扩到 10+）、60/40 倾向、同族连刷衰减、组合形态名、自动结算、12 条突变效果、视觉/碰撞缩放分离
  - `src/main.ts`：写入 `recentHunts`、不再清空本局基因、去掉三选一弹窗、模块化几何身体、结算基因链
  - `src/rewards.ts`：`canChallengeBoss(印记 + 进化阶段)`
  - 帮助条与结算文案改为「猎杀决定进化」
- 为什么：让单局进化本身可读、可玩，并给以后互吞留下同一套基因接口
- 明确不做 / 后置：DNA、中途存档、茧化、第 7–10 次内容、30 分钟新地图事件、音频、触控、英文本地化
- 验收 / 证据：
  - 83 项测试通过
  - `npm run build` 成功
  - 浏览器实机：无选牌弹窗，HUD 显示 `原始形态 · 0/6`、六族倾向、`猎杀决定进化 · 第6次后可挑战Boss`
- 已知限制：
  - 身体仍是几何原型
  - Phaser 包体超过 500kB 警告（记录为后续工作）
  - 三条猎杀路线的实机外观差异尚未做完整试玩验收
- 下一道门：同一个初始角色，分别主猎不同种族，最终外形和玩法必须一眼能分

## 2026-08-13 · 决策：魂球分级要做，开放世界现在不做

- 类型：决策
- 玩家可见结果：尚未改代码。当前普通怪和精英怪仍掉同一颗绿色生物质（精英只是更肉、带词缀），所以猎杀决策偏死板。
- 做了什么：评估「白/红/金魂球 + 力量敏捷魔法精神 + 精英 buff + 开放世界」是否该立刻开工
- 为什么：
  - **魂球分级成立。** 玩家要能看见：打杂兵、打精英、打 Boss 吃进身体的东西不一样。白球推进生物质和基因；红球给更多生物质、更强基因倾向，并可把该精英的词缀变成一次短 buff 或下一次生长的强化；金球一次性推高阶段并倾向组合/终态器官。算法仍是猎杀决定进化，只是掉落有等级，不要做成三套进化树。
  - **独立属性板不成立。** 六族基因已经是构筑。再加力量/敏捷/魔法/精神会变成第二套 RPG，和獠牙≈力量、翼族≈敏捷、裂隙≈魔法、甲壳≈精神重叠。若 HUD 需要「力量 12」，应从基因等级派生，不要每颗魂球另掷属性点。
  - **开放世界现在不做。** 地图已经是 5200×3200 三生态加迷雾。空的原因是遭遇点和猎杀差异不够，不是矩形太小。放大地图会挤掉「三条猎杀路线长成三种生物」这道门。产品基线也把开放世界列为验证前非目标。
- 明确不做 / 后置：
  - 开放世界、无缝大地图、新大陆、装备栏
  - 独立于基因的四维加点/洗点
  - 永久 buff 栏堆叠（精英词缀最多变成短时效果或下一次生长修饰）
- 验收 / 证据：对照现有掉落：普通与精英 `biomassValue` 默认都是 20，只有分裂体是 5；Boss 不掉魂球。死板来自掉落无等级，不是来自地图面积。
- 下一道门：先完成三条猎杀路线验收。通过后在现有地图做魂球分级（白/红/金）和派生属性显示。世界变「不小气」靠现有三生态里增加精英遭遇和猎杀差异，不靠把地图做成开放世界。

## 2026-08-13 · 评估：怪物难度现在不调

- 类型：评估 / 决策
- 玩家可见结果：无代码改动，战斗数值保持原样
- 做了什么：对照进化 v2、魂球并行线、以及 `difficulty.ts` / 遭遇密度 / 玩家承伤，判断「怪太软」要不要现在拧
  - 玩家可以死：利爪猎兽约 115 生命，林地扑击约 14 点净伤，连续吃 8–9 下就会倒；接触伤害走 `endRun('death')`
  - 但挑战偏软是结构问题，不是差 20% 伤害：全图约 27 个 1v1 点位、精英只有 3 个印记守卫、威胁只跟生态走不跟进化阶段走；进化后玩家加血/加伤/击杀回血，林地仍是威胁Ⅰ
  - 普通与精英默认仍掉同一颗 20 生物质，打危险猎物的回报还没分开
  - 按 validation：这是 P2 手感，不是 P1（跑不完、控不了、几乎不可能死）
- 为什么：**后期调。** 「没有失败就没有猎杀决策」成立，但现在缺的猎杀杠杆是掉落等级和阶段威胁，不是把 24 种怪的表重做一遍。过早数值战争会拖住进化验收，也会和正在落地的魂球抢同一批掉落/精英文件，落地后再重调一次。
- 明确不做 / 后置：
  - 现在不改怪物血量、接触伤害、生态倍率、Boss 数值、玩家生命
  - 不扩地图、不加遭遇点、不开威胁导演
  - 毒素致死仍送回营地（违反「野外死亡结束本局」）记为独立一行修复，不并进这次评估、也不当平衡旋钮
- 验收 / 证据：只读 `src/difficulty.ts`、`src/monsters.ts`、`src/boss.ts`、`src/world.ts`（27 遭遇 / 3 精英）、`src/main.ts` 承伤与死亡；未改战斗代码
- 下一道门：继续魂球分级（白/红/金）。难度窗口挂在第 3 项：魂球落地后、做「可选 Boss + 威胁随阶段上升」时再调。届时只拧两处：阶段威胁（含精英密度）和低危区白球收益递减；现有 `BIOME_DIFFICULTY` 留作配置旋钮，不先开 24 怪平衡表。

## 2026-08-13 · 评估：以「达尔文进化岛」为幻想北极星，现在不加新地图

- 类型：评估 / 决策
- 玩家可见结果：无代码改动，无新地图、无新生态
- 做了什么：对照魔兽争霸自定义图「达尔文进化岛」（亦称进化岛 / Darwin Evolution Island）的公开玩法，评估「整个游戏参考它、优化它、增加更多设定和地图」是否成立。核对来源限于公开介绍，不编造该图具体岛屿/商店布局：
  - 核心循环有据：吃不同小动物决定进化方向；食物量到阈值就进化；也可吃其他玩家；不同猎物回报不同（如弱小猎物给经验/金币，其他生物还可能给随机技能）
  - 阶段压力有据：高等级后再刷弱小猎物收益递减；11 级可选终极进化并进入死亡模式（视野全开、被杀不能复活）
  - 并行系统有据、但属 WC3 图包袱：装备购买/合成、技能栏、称号、惊喜礼物/神符、1–12 人对抗
  - 分区猎场是玩法，不是平方公里：公开描述是多区域岛屿上的野怪与资源点，不是开放世界
- 结论：
  - **北极星成立。** Evolution Arena Lite 已经在偷这张图真正好玩的那一层：猎杀/吞噬决定形态，而不是暂停选牌。这与既有决策「猎杀决定进化」一致。
  - **现在加更多地图不成立。** 当前世界已是 5200×3200、三生态（幽影林地 / 腐根沼泽 / 烬火遗迹）、约 27 个遭遇点和 3 个精英。空的原因仍是猎杀杠杆不够（掉落无等级、威胁不跟阶段走），不是矩形太小。立刻新增大陆会挤掉三条猎杀路线验收，并和魂球抢同一批遭遇/掉落文件。
  - **「优化」是做浏览器单人版的可读进化，不是复刻 WC3 RPG。** 我们已有 6 族基因、自动生长、倾向条；白/红/金魂球是下一层「猎物危险=回报」。装备栏、巨大技能栏、开局 PvP 会把验证窗口从「吃什么变成什么」拧成另一款游戏。
- 该偷（现在 / 下一阶段就能强化，且不扩地图）：
  - 猎杀即进化、吃什么长成什么（已落地 v2）
  - 猎物危险 = 回报（对应白/红/金魂球；弱区白球后期递减对应进化岛「高等级再刷小猪小鹿变穷」）
  - 分区威胁：现有三生态做成「敢不敢进更危险的区吃更强的东西」，用红球精英、金球 Boss、阶段威胁，而不是第四张图
  - 外形可读：每级/每条路线一眼能分（对应三条猎杀路线验收）
  - 玩家互吞：远期北极星，接口保持 `PreyGenes → BodyChange`；现在不做匹配
- 不该现在抄（会挤掉当前验收门）：
  - WC3 式巨大技能栏、装备合成、称号、随机神符商店 → 挤掉猎杀路线可读，并另起一套成长
  - 多层岛屿 / 新大陆 / 开放世界 → 挤掉三条路线验收和魂球分级
  - 大量固定进化树或 380+ 单位模型 → 违反模块化身体，CAD 500 / 8 周撑不住
  - 开局就 PvP → 违反暂缓联机；单机怪物应先当互吞教程
- 第 4 生态 / 第 4 张图的开门条件：三条猎杀路线通过、魂球落地、阶段威胁让「进更危险的区」已经成立，且玩家仍觉得三生态猎物种类不够支撑定向进化。在此之前，「更多地图」只等于现有图里的遭遇差异，不等于新大陆。
- 明确不做 / 后置：
  - 现在不改游戏代码、不加第 4 生态、不画新大陆、不抄装备/技能栏/开局 PvP
  - 不和并行中的魂球实现抢 `src/soul-orbs.ts` 及掉落/精英文件
- 验收 / 证据：只读 `docs/DEVELOPMENT-LOG.md`、产品基线、`src/world.ts`（5200×3200 三生态）；公开资料核对进化岛核心玩法；未改战斗或世界代码
- 下一道门：不变。仍是三条猎杀路线验收；魂球分级若已在另一条线落地，不要抢文件。难度与「分区感」并入第 3 项「可选 Boss + 威胁随阶段上升」。
