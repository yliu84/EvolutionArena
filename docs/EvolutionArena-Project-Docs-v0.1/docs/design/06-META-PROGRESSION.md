# Meta Progression and Collection

## Goal

Give the player reasons to return without making early runs permanently weaker.

## v0.1 / Early Features

### Gene Encyclopedia
Records discovered species, genes and mutation families.

**Current status:** the 24-species kill/discovery bestiary is implemented. Gene-family and final-form records remain.

### Creature History
Save a lightweight record of notable final builds:
- mutation path;
- survival time;
- boss result;
- optional screenshot/thumbnail later.

**Current status:** not implemented. This is the preferred next persistent replay hook before permanent stats or currency.

### Discovery Unlocks
A newly discovered gene/mutation may become eligible in later runs. Unlocking increases variety rather than raw stats.

## Later Features

- challenge modifiers;
- cosmetic body materials;
- named achievements;
- rare evolutionary branches;
- daily seeded run;
- build sharing.

## Avoid During Validation

- permanent +damage/+HP;
- grind currencies that mask weak gameplay;
- daily chores;
- monetization loops.
