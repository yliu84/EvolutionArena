# Core Loop and Run Pacing

## Moment-to-Moment Loop

**Observe → choose prey → approach → fight → consume → adapt → seek stronger target**

The key design distinction is that the player does not stop to choose cards. The player *feeds the evolution resolver* through hunting decisions, sees the emerging tendency, and may resist one pending growth per run.

## Run-to-Run Loop

**Start → experiment with route/build → die or win → inspect creature → discover something → imagine alternative → replay**

## 12–18 Minute Validation Pace

| Time | Phase | Expected Experience |
|---|---|---|
| 0:00–1:30 | Survival | safe prey, first tendency preview |
| 1:30–4:00 | First adaptations | Stages I–II, route becomes visible |
| 4:00–8:00 | Hunting | Stages III–IV, biome and elite choices matter |
| 8:00–12:00 | Specialization | Stage V, sigil route and risky targets |
| 12:00–18:00 | Apex decision | Stage VI and boss, or voluntary overgrowth |
| 18:00+ | Observed overgrowth only | no hard timer; world and boss pressure escalate |

## “One More Run” Hooks

At least three should fire at the end of a typical run:
- “I almost completed that synergy.”
- “I never found the rare creature I saw earlier.”
- “What if I hunted the marsh first?”
- “I unlocked/discovered a mutation I want to try.”
- “My final creature looked great; I want a stranger one.”
- “I can beat that boss with a different build.”

## Anti-Boredom Rules

- No long empty travel.
- No more than ~20–30 seconds without a decision, encounter or discovery.
- Evolution preview and commit must not pause combat.
- Trivial prey should stop being optimal as the player grows.
- Strong builds must change play style, not only DPS.
