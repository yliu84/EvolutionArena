# Goal 10 — River Valley 轻量氛围天气导演

## 玩家结果

每局 River Valley 有一种清楚且不打扰战斗的环境情绪：**晨光**、
**薄雾**或**小雨黄昏**。它们改变远景、雾和光的情绪，但不会把夜色压到
看不清 Boss 地面预警、敌人轮廓或手机 HUD。

用于可复现验收：`?weather=dawn`、`?weather=mist`、`?weather=rain`；没有
该参数时，天气由本局已有种子稳定选出。

## 性能边界

- 不启用全屏后处理、体积云、屏幕空间雨滴、动态昼夜循环或全地图粒子。
- 雨只是一批相机附近的复用线段；桌面上限 64 条、粗指针设备 36 条，
  都是一份几何、一个 draw call。
- 天气不创建碰撞体、伤害、减速、能见度数值或 AI 状态；它是纯表现层。
- 雾、太阳与半球光只朝目标值插值，不触发阴影贴图重建。

## 验收

1. 三种 URL 都能明显读出不同情绪；小雨黄昏仍可看清 Boss 圈、锁定板和移动路径。
2. River Valley 的浅滩到源头仍从开阔到冷暗，天气不抹掉区域递进。
3. 1440×900 与 844×390 均无溢出、console error/warning；手机横屏保留 Move/Lock/Attack。
4. `npm test`、`npm run build` 通过；雨天不增加可见的重复实体或随帧增长的内存。
5. 用现有 PERF 读数记录晨光与小雨的 FPS / P95，雨天不得造成明显退化。
