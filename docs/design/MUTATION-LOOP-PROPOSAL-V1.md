# 变异循环 · 设计提案 V1

状态：提案，未实施。等用户确认后再动代码。
日期：2026-08-17

## 一、问题

用户实测：2 分钟通关，三条进化线「除了皮肤不一样其它都差不多」。

核对代码后确认这不是错觉：

**内容总量**（`src/gloamwood-3d-ecology.ts`）

| 波次 | 组成 | 生物质 |
| --- | --- | --- |
| 1 | 裂牙 ×2 | 16 |
| 2 | 岩盾 ×1，群生 ×2 | 22 |
| 3 | 裂牙 ×1，岩盾 ×1，群生 ×4 | 38 |
| | **11 只小怪 + 巢卫 + Boss** | **76** |

**决策总量**：整局 **1 次**（0 阶 → 1 阶三选一）。

**选项的实际差别**（`src/i18n.ts`）

| 共生幼巢 | 击杀回血 7 · 生物质 +18% · 伤害 −6% |
| --- | --- |
| 猎行菌群 | 移速 +14% · 生物质 +12% · 生命 −10 |

伤害 −6% 在实际游玩中感觉不到，也不会让任何玩家改变打法。

**结论**：一局只有一个决策点的 roguelite 不是 roguelite，是带换装界面的线性关卡。往里面加技能栏只会给一个没有理由重玩的游戏多加几个按钮。

## 二、方向：不要照搬装备/等级/技能

那是别的游戏的解法。这个项目手里有一个别人没有的东西——**玩家的身体本身**。

RPG 的诱惑是外部的（捡到什么、装上什么）。这里的诱惑应该是内部的：**我这局能长成什么**。

| RPG 的钩子 | 本作的对应物 | 美术成本 |
| --- | --- | --- |
| 装备 | **变异**：改规则，不改数值 | **零** |
| 升级 | **形态进化**：身体真的换掉 | 高（一只 ≈ 一轮完整 Meshy 流程）|
| 新技能 | **普攻链随身体改变** | 中（只需动画）|

第三条已在 2026-08-17 验证：群生的四段链（扑→爪→爪→咬）与裂牙的三段链在权威层面确实不同，且**没有技能栏、没有蓝条、没有冷却**。

## 三、把「进化」拆成两层

现在只有一层，所以它既贵又稀少，一局只能来一次。

### 形态进化（一局 2 次，看得见，贵）

0 阶 → 1 阶 → 2 阶。2 阶资产（`scarlet-hunter`）已在仓库中，只是当前一局根本走不到。

### 变异（一局 5~6 次，零美术成本，变化量的真正来源）

每积累一定生物质弹出三选一。**每一条改变一条规则，不是一个百分比。**

判定标准只有一条：**玩家会不会因为它改变打法。**「伤害 −6%」不会；「击杀后 2 秒内跃扑距离翻倍」会。

### 关于吸引类效果（2026-08-17 用户否决后修订）

原设计的「荧光诱捕」把敌人从更远处拉过来。**这条不成立**，理由有两层：

1. **本作现在所有猎物都是无条件扑上来的巢穴守卫**，没有主动怪/被动怪之分。在这个前提下，任何「吸引」都只能提高死亡率，不可能成为收益。
2. 即使以后大地图区分了主动怪与被动怪，**吸引必须只作用于被动怪**才是工具。拉动主动怪等于把玩家推进一场他没选择的包围战——用户的原话是「要是吸引太多远处怪，就没有办法玩了，死亡几率太大」。

改为 **孢子晕**：靠近玩家的敌人移速降低 40%，代价是孢子吃掉 25% 的生物质——**用成长速度换安全**，这是一个真实的 roguelite 取舍。

**主动怪 / 被动怪的区分是任何真正的吸引类变异的前置条件。** 在它存在之前，本层不得加入任何扩大仇恨范围的条目。

## 五、触发节奏

一局可得生物质 76（不含巢卫与 Boss）。

**每 14 点生物质触发一次** → 一局约 5 次变异，分布大致是：

| 时点 | 累计生物质 | 说明 |
| --- | --- | --- |
| 第 1 波末 | 16 | 第一次变异，此时玩家刚学会操作 |
| 第 2 波中 | 28 | |
| 第 2 波末 | 38 | 与形态进化（0→1 阶）重合，此处只给形态，不给变异 |
| 第 3 波中 | 52 / 66 | 两次 |
| 巢卫后 | — | 第二次形态进化（1→2 阶）|

**形态进化点不同时给变异**，否则两个选择叠在一起，玩家两个都记不住。

## 六、与现有 Genes 系统的接口

现行规则（不改）：Genes 只**加权**随机候选，永不保证。这条已写进引导文案并有测试守着。

变异沿用同一条规则：

- 变异池按**当前累计 Genes**加权。吃了很多岩盾，岩盾系变异出现概率上升。
- **权重永不变成保证。** 低权重变异始终可能出现——这是「异变」的叙事，也是重玩变化量的来源。
- 已选过的变异不再进入本局池子。

这样「吃什么 → 变成什么」这条因果链第一次在一局之内被玩家看见 5 次，而不是 1 次。

## 七、跨局的钩子：基因库

单局再好玩，打完就没了。RPG 靠等级留人，roguelite 靠解锁。

**你杀过的物种进入基因库。** 库中的物种会成为后续局中变异池的条目，或可选的起始形态。

第一局池子里只有基础条目；十局之后有二十条。**这就是「等级」，而且它完全长在本作的世界观里，不需要借用任何 RPG 概念。**

实现上它只需要一个持久化的物种计数（`localStorage`，与语言选择同一套机制），不需要账号、不需要服务器。

## 八、权威边界（硬约束）

以下几条不是建议，是这个项目已经付过代价的教训：

1. **所有变异效果必须走同一条权威路径。** 伤害经 `attackBaseDamage()`，射程经 `attackRange()`。2026-08-17 刚修完三处各自为政的伤害查表（`combatProfile` / `combatHitFeedback()` / `resolvePlayerContact` 内联表），变异是最容易再犯这个错的地方。
2. **随机必须走种子。** Goal 3 的验收包含种子可复现，变异抽取若用 `Math.random()` 会直接破坏它。
3. **表现层永不决定伤害。** 震动、闪光、粒子、表现击退都不得参与判定。
4. **不加技能栏、蓝条、独立冷却。** 变异是被动规则改变，不是可主动释放的能力。这条边界由用户设定，本提案完全遵守。
5. **不改地图环境、神殿、光照、植被。** 环境是独立工作流。

## 八点五、一个实测数据：巢卫血量撑不住变异叠加

排查「巢卫只攻击一次」时顺带量到的。用真实数值模拟整场巢卫战（230 血、真实击退、群生四段链、自动接敌停靠距离）：

| 玩家伤害倍率 | 战斗时长 | 巢卫打出的攻击 |
| --- | --- | --- |
| ×1（无变异） | 25.5s | 13 |
| ×1.35（薄皮） | 17.1s | 8 |
| ×1.8 | 7.9s | 4 |
| ×2.4 | **3.9s** | **2** |

**这不是缺陷，是平衡问题。** 玩家伤害翻倍时，巢卫从「一场 25 秒的攻防」变成「4 秒内被删除」，它的攻击机会从 13 次掉到 2 次——玩家几乎不会挨打，也就没有任何压力。

变异层一旦上线，敌人血量必须跟着走，否则「叠 build」的结果是把内容全部跳过。这直接对应第九节的第 2 步「难度调到会输」——**不输就没有第二局**，而现在的问题是叠满 build 之后连挨打的机会都没有。

## 八点七、第一次实测反馈（2026-08-18）

用户完整打了一局，反馈三条：

**1. 变异出现太频繁。** 目标是**约 3 分钟一次**，且**越往后越难变异**。

**已改为按里程碑解锁（2026-08-18 第二轮）**，递增消耗方案作废。理由见 `OPEN-MAP-RUN-STRUCTURE-V1.md`：生物质在开放地图上是无界的，按它解锁等于「谁肯刷谁就无限变强」。

demo 地图上的五个里程碑，每个给一次变异、每个只给一次：

| # | 里程碑 | 阶段 |
| --- | --- | --- |
| 1 | 第一波清空 | 狩猎 |
| 2 | 第二波清空 | 狩猎 |
| 3 | 窝点清空 | 狩猎结束 |
| 4 | 巢卫击破 | 守卫 |
| 5 | Boss 进入二阶段 | Boss |

**里程碑刷不出来**：每个一局只发生一次，而且每个都比上一个更深。「越往后越难变异」不是价格上涨，而是**下一次变异在更危险的地方**。

开放地图上这五个会换成「进入区域 ×3 + 区域首领 ×2」——形状不变，只换数据源。所以运行时记录的是**不透明的 id**，它并不知道什么是「波」。

但必须说清楚：**「3 分钟一次」靠调节奏是达不到的。** 当前一局只有 2.5 分钟，按 3 分钟间隔算，一局连 1 次变异都不到。**间隔和局长是同一个问题，局长必须先涨上去。**

**2. 出现过犹豫**——两个都想要、只能选一个。这是这一层设计成立的直接证据。

**3. 通关 2.5 分钟，剩 2/3 血，但中途死了几次。**

第 3 条比前两条都严重：**死亡目前是免费的。**

查过代码：狩猎阶段死亡只会把活着的猎物挪回窝点周围重排，**生物质、基因、击杀数、已选变异全部保留**，`runDeaths` 只用于调试显示，不产生任何后果。

所以「死了几次仍然 2.5 分钟通关、还剩 2/3 血」不是玩家强，是**这一局根本没有失败状态**。

roguelite 的重玩欲望来自「这次死在哪里 → 下次换条路线」。**死亡不要钱，就没有那句话的前半句。** 这是第九节第 2 步「调难度到会输」真正要解决的东西——不是把敌人调硬，而是**先让死亡有代价**。

## 八点八、死亡的代价：一局 3 条命（用户 2026-08-18 选定方案 C）

三个候选：A 死亡即结束本局；B 死亡损失进度；**C 有限复活次数**。用户选 C。

**已实现**：一局 **3 条命**，每次死亡消耗一条，归零即本局结束。

几个实现上的决定：

- **狩猎、守卫、Boss 三个阶段全部走同一个扣命入口。** 之前守卫阶段死亡是直接判负、狩猎阶段死亡完全免费——两套规则。现在无论被什么杀死，代价一样，预算不能靠「死在哪个阶段」绕过。
- **在竞技场里花掉的命，复活点也在竞技场内。** 狩猎的出生点在两个竞技场之外，而这两场战斗都无法重新进入——照旧逻辑复活会把玩家瞬移出战斗，等于意外结束遭遇。
- **「蜕壳」变异变成「一次不消耗存活次数的死亡」。** 它在玩家被判定为死亡之前就在受伤闸门里复活了，所以天然不扣命——不是第 4 条命，而是一次免费的死。方案 C 让这条变异第一次真正值钱。
- **存活次数显示在 HUD 资源行里。** 看不见的预算没法拿来做决策。

3 条是刻意宽容的。**重点不是它经常归零，而是它能归零。**

## 九、建议的实施顺序

**第一步只做变异层，完全不碰美术。**

理由：它是唯一一个**不需要任何新模型就能验证「玩家愿不愿意再来一局」**的改动。

如果加了 5 次变异选择、玩家仍然两分钟就腻，那问题不在内容量而在别处——那时候再投美术才不算浪费。反过来先做形态，会花两周做一只怪，然后发现问题不在那儿。

顺序：

1. 变异系统 + 前 8 条（每条都能复用现有系统）
2. 难度调到会输——不输就没有第二局
3. 一局内第二个形态进化点（2 阶资产已存在）
4. 基因库（跨局解锁）
5. **然后**才谈技能

## 九点五、这些数字只对 demo 地图成立（用户 2026-08-18 提出）

用户指出：目前所有测试都在这张 demo 地图上，而正式版是一张**开放大地图**——探索、打怪、进化，还要加上恢复道具和限时 buff。

这个提醒是对的，而且必须现在记下来，否则会有越来越多的东西建立在错误的地基上。

### 会失效的（demo 专属）

| 现有决定 | 为什么会失效 |
| --- | --- |
| 变异消耗 14 / 19 / 26… | 按「一局 76 点生物质」标定的，开放地图没有这个总量 |
| 一局 3 条命 | 按 2.5 分钟一局标定；一局变成 20 分钟后 3 条太少 |
| 敌人血量（巢卫 230） | 按固定三波节奏标定 |
| 「三分之一局出现第一次变异」 | 开放地图没有「三分之一局」这个概念 |

### 会留下的（与地图无关）

- 变异是**声明式数据**，由既有权威路径读取——这是结构，不是数值
- 一个修饰值写入点、一个受伤闸门
- 叠加规则（乘数连乘、加成累加）
- Genes **只加权、永不保证**
- 种子可复现
- 每个形态有自己的普攻链
- `(stage, family)` 资产键
- 存活次数这个**机制**（数字会变）

### 一个现在就该改的漏洞：变异不能按生物质总量解锁

现在的门槛是 `gloamwoodMutationOffersEarned(biomass)` —— **纯粹按累计生物质**。

demo 地图里生物质总量是固定的（76 点），所以这没问题。**开放地图里生物质是玩家自己决定的**：多刷怪就多拿。于是「变异」变成「谁肯刷谁就无限变强」，而这恰恰是用户提出的「越往后越难变异」的反面。

开放地图上真正合适的闸门，必须是**玩家刷不出来的东西**：

1. **深度 / 区域**——进入更危险的区域才解锁下一次变异。天然对应「越往后越难」，也奖励探索而不是原地刷。
2. **首领击杀**——每个区域首领掉一次变异。数量可控，且与地图结构绑定。
3. **时间**——用户提的「约 3 分钟一次」。最简单，但会奖励挂机。

**建议 1 为主、2 为辅**：深度决定节奏，首领作为额外奖励。生物质则回到它本来的角色——**进化（换身体）的货币**，而不是变异的货币。

这一改不必现在做，但**在开放地图动工之前必须做**，否则地图一上线，变异就是可刷的。

### 恢复道具与限时 buff 是第三层，不是变异

用户提到要加地图道具（回血、限时 buff）。它们和变异是不同的东西，不应混在一起：

| | 来源 | 时长 | 有无代价 | 玩家能否选择 |
| --- | --- | --- | --- | --- |
| **形态进化** | 生物质 | 永久 | 有 | 三选一 |
| **变异** | 深度 / 首领 | 本局永久 | **有** | 三选一 |
| **地图道具 / 限时 buff** | 探索捡到 | 即时或限时 | **无** | 捡不捡 |

关键区别是**代价**。变异必须有代价，它才是决策；道具不该有代价，它才是探索的奖励。两者混淆会让探索变成负担。

**表现上必须区分。** 现在的变异图标是永久累积的圆形图标。限时 buff 如果用同一种图标，玩家会把「本局永久」和「30 秒后消失」当成一回事。限时的那类需要**倒计时环**或者放在另一行——这一条在做道具之前就要定下来。

另外：**回血道具会直接削弱刚做好的存活次数系统**。满地图回血 = 死亡又变便宜了。道具的投放密度必须和存活次数一起调，不能各调各的。

## 十、本提案不做的事
