# 开放地图 · 整体平面图方案（四选一）

日期：2026-08-18
用途：给用户选一套作为开放地图的拓扑基础。选定后再定区域范围、窝点候选位与过渡点坐标。

四张图都基于同一套既有资产与规则，只有**拓扑**不同：

- 8 个 MapLab 4 窝点原型，按核心血量分三层（18–20 / 22–26 / 28–30）
- 一局穿过三个区域，每区清 2 个窝点
- 窝点从**同层候选位中随机抽取**，所以两局路线不同
- 区域之间的过渡点就是区域首领所在处
- 五个变异里程碑 = 进入区域 ×3 + 区域首领 ×2

## 关键取舍

**B 的路线选择权和「越往后越难」直接矛盾。** 玩家能任意顺序进三叶，深度就不再是难度。要救它只有两条路：给叶排死难度（等于取消选择权），或按进入顺序动态缩放敌人强度（实现复杂，而且玩家会察觉数值在变）。

**C 是唯一「隘口天然就是首领位」的方案。** 其余三套都要额外解释「为什么这里过不去」。C 的代价是最不像开放世界，更像三段关卡。

**D 的视觉辨识度最高，代价是三倍的地貌美术量**，而且渡口是纯移动时间——如果渡口里没有内容，那段路就是空的。

**A 几何最规整，但外环周长最长、危险最低**：玩家会在最无聊的地方走最多的路。可以靠把外环做窄来缓解。

## 结构确定（用户 2026-08-18）：**多张分立地图，不做单张巨型开放世界**

用户提出：不要那种特别大的开放世界，而是**多张风格不同的地图**（废墟、平原、海岛、雪地、火山……），每张玩 20–30 分钟，后期慢慢加。

**这比我原来的方案好，而且它顺手解决了本文档的选择难题。**

### 为什么更好

1. **一张地图就是一个完整单局。** 20–30 分钟正好装得下「约 3 分钟一次变异」——这是本项目一直放不下的那个目标；2.5 分钟的局里它根本不成立。
2. **加内容是加法，不是重构。** 单张巨型世界里扩一块区域要重新平衡整体；分立地图加一张就是加一张，已有的不受影响。
3. **它把「都长一样」这个问题在地图层解决掉了**——和形态层已经解决的方式相同：不是把一张图做大，而是做出**不同的东西**。
4. **项目本来就是多地图心智模型。** `maplab=1..5` 就是五张分立地图，路由层已经按这个组织。
5. **既有的 8 个窝点原型可以按主题分配到不同地图上**，每张图只从自己的主题子集里抽——窝点复用，主题不复用。

### 四套拓扑不再是「选一个」，而是「每张地图用合适的那个」

这是最大的收获。原本我在纠结选 C 还是 D，其实**四套都留着**，按地图主题分配：

| 主题 | 适配拓扑 | 理由 |
| --- | --- | --- |
| 河谷 / 雪地峡谷 | **C 河谷长带** | 地形天然线性，隘口就是山口 |
| 海岛 | **D 群岛** | 渡口即浅滩，边界物理不可绕 |
| 火山 | **A 同心三环** | 越靠火山口越危险，深度天生可读 |
| 废墟 / 平原 | **B 中枢三叶** | 空旷地形适合自由路线；难度靠区域本身而不是顺序 |

**B 的「深度不可读」问题在这个框架下不再是问题**——它只用在那些「难度来自区域本身」的地图上，而不必承担全局的深度递增。

### 我建议的第一张新地图：河谷（C 拓扑）

现有的幽影林地是森林，已经存在。第二张地图是**「加一张地图到底有多贵」这个问题的第一次真实测量**——和岩盾是「做一只怪多贵」的第一次测量一样。

选河谷 / C 拓扑，因为它美术量最小（三段，不是一整张世界），能最快得到那个成本数字。拿到之后再决定后面几张的排产密度。

### 一个必须现在指出的张力：20–30 分钟 × 3 条命

一局 25 分钟、只有 3 条命，意味着**一次失误可能报废 25 分钟**。这不是宽容，是惩罚。

三条出路：

1. **每进入新区域补 1 条命**（此前已在开放地图提案里建议过）。20–30 分钟的地图若有 4 个区域，总容错就是 3 + 3，够了。
2. **区域即检查点**：死光后从当前区域开头重来，保留已获得的变异与形态。
3. 缩短单局到 10–15 分钟。

**建议 1 + 2 一起。** 这两条都不会让死亡变免费——你仍然会损失时间和推进度，但不会一次损失 25 分钟。

### 需要一并决定的：怪物是否随地图换

如果每张地图都要有自己的怪，成本会立刻失控（一张图 × 若干新物种）。

**建议：6 个家族跨地图复用，每张地图只做自己的首领。** 家族最多做贴图/配色的地域变体，不做新模型。这样一张新地图的生物成本就只有 1–2 个首领，而不是一整套生态。
