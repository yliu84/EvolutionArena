## 一、长度是从时间预算推出来的，不是拍的

用户目标：一张地图玩 20–30 分钟。取中值 25 分钟（1500 秒）。

| 项 | 秒 |
| --- | --- |
| 6 个窝点战斗（6 × 110） | 660 |
| 2 个区域首领（2 × 70） | 140 |
| 终局 Boss | 110 |
| 选择面板 7 次 × 15（5 变异 + 2 进化） | 105 |
| **战斗与选择合计** | **1015** |
| 剩余移动时间 | 485 |

移动路径总长 = 485 × 6.2（`PLAYER_SPEED`）× 0.70（路径效率）= **2105 世界单位**
减去支线往返（6 窝点 × 2 × 45）= 540
**→ 主路单程 ≈ 1565，取整 1600**

端到端不停步 = 1600 / 6.2 ≈ **4.3 分钟**。

对比：现有幽影林地是 50 × 36，横穿 8.1 秒。**河谷是它的 32 倍长。**

## 三、随机化规则

**位置与原型都随机。**

- 每区 3 个候选位，实际只激活 **2** 个 → 每区 3 种位置组合
- 原型从该层抽取：一层 3 个、二层 3 个、三层 **只有 2 个**

三层只有两个原型（黑茧高巢、沉没母巢），所以**必须靠位置随机来保证第三区仍有路线变化**——否则每局第三区都一样。这是位置随机存在的原因，不是锦上添花。

## 四、与已实现系统的对接

| 系统 | 对接方式 |
| --- | --- |
| 变异闸门 | 5 个里程碑 = 进入区域 ×3 + 区域首领 ×2。运行时记录的是不透明 id，只需换数据源。 |
| 存活次数 | 起始 3；经过 R1 / R2 各补 1，上限 4。 |
| 检查点 | 命归零时从当前区域起点重来，**保留已获得的变异与形态**。25 分钟的局不能因一次失误全废。 |
| 形态进化 | 区域一末尾（0→1 阶）、区域二末尾（1→2 阶），由生物质解锁。 |
| 回血 | 沿用窝点的 `heal` 奖励（24–38），**不撒落地拾取**。 |

## 五、需要环境工作流提供的

本规格不含任何美术改动，只需要三项结构：

1. 沿 x 0–1600 的可行走边界（按第二节的半宽表）
2. 9 个窝点候选位的地面（各需容纳 `combatRadius`）
3. 两处隘口与终局场地的地形

主题为河谷：谷底主路、两侧岩壁、三处开阔盆地。**不要求改现有幽影林地的任何资源。**
