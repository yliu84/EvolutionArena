# Goal 9 — 灵活狩猎

## 玩家结果

River Valley 的第一反应不再是贴住目标、按住攻击、互相掉血。玩家可以在
Boss 预警出现时立即向任意方向移动；这会放弃正在进行的普攻和其缓冲的下一击，
但保留当前锁定。预警结束后的反击仍只使用原有的单键基础攻击。

目标循环：**接近 → 攻击 → 看到预警撤离 → 在收招期反击**。

## 范围

- 方向输入立即优先于自动贴近和基础连招；不等待模型先转到移动方向。
- 模型仍平滑转身；碰撞、地形、锁定目标和攻击接触的距离/八度朝向判定不变。
- 方向输入取消活动挥击、一次缓冲后续挥击和 `primaryHeld`，下一次主动攻击从基础起手开始。
- 桌面键盘和既有手机摇杆采用同一权威规则。

## 明确不做

- 不增加闪避技能、技能栏、额外手机按钮、法力或冷却系统。
- 不改伤害、生命、Boss 伤害、攻击判定、进化、地图、美术或模型。
- 不把镜头震动、动画或特效作为位移/无敌的权威来源。

## 验收

1. 从完全反向的朝向输入移动，首帧即可有位移；模型仍继续朝移动方向转身。
2. 普攻开始后输入方向，当帧取消未结算的普攻与缓冲，不再自动重开连招。
3. 锁定保留，玩家可在安全位置再次用原有攻击键反击。
4. Boss 预警期间，桌面和 844×390 手机横屏均可执行撤离；无控制台 error/warning。
5. `npm run build`、聚焦测试与全量测试通过；不出现新的 P0/P1。
