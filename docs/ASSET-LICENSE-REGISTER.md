# Evolution Arena Lite — Asset license register

Last reviewed: 2026-08-24  
Scope: current browser build and itch.io Free Alpha preparation

This is the public-safe source-of-truth for shipped third-party and AI-assisted
assets. It intentionally contains no invoice, account, email address, payment
amount, downloaded source mesh, or private screenshot. Those records remain in
the project owner's private archive.

## Credits for the Alpha page and in-game credits

The credit is required for the CC BY source chain below. It also makes the
generation method clear for the paid Meshy assets, without exposing the owner's
private billing information.

## Release checks

Before publishing an itch.io build, verify that every runtime model in
`public/assets/quality-3d/models/` is covered by one of the rows above, and
that the public game page carries the listed credit. Do not upload private
invoices, private Meshy screenshots, original owner downloads, account details,
or unredacted billing exports to GitHub or itch.io.
