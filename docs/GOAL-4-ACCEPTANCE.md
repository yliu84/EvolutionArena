1. 在外部 Chrome 打开正式入口。
2. 打开开发者工具的设备工具栏，选择 Responsive，输入宽 `844`、高 `390`、缩放 `100%`。
3. 在控制台确认 `innerWidth === 844 && innerHeight === 390`。
4. 从正常入口至少完成移动、锁定、一次普通攻击并打开进化界面；若时间有限，可在完成自然局后重新加载同一种子检查横屏。
