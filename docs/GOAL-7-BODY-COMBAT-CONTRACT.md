# Goal 7 — 身体型普攻进化表现契约

## 不可妥协的规则

玩家只使用移动、锁定目标和同一个普通攻击输入。以下效果不是技能、
不是额外按键，也不是藏在状态页里的百分比。每一项必须同时拥有：

1. 静止时可从轮廓或材质读出的身体变化；若无经过近/中/远视角验收的
   作者资产，不允许用运行时基本几何体冒充；
2. 普攻前摇、命中帧或收招中的专属动作语言；
3. 敌人或玩家能看到的命中反应；
4. 由既有战斗权威决定的真实规则；
5. 桌面与横屏手机均可识别的最小表现。

视觉从权威事件读取结果，绝不反向决定命中、伤害、范围、击退或回血。

| `shell-symbiosis` → **硬壳格挡** | 背、肩与尾根出现厚重甲片回应；受击时甲片短促亮起并溅出碎屑 | 受击是顶住/沉下，而非轻飘飘闪白 | 固定减伤，并把一部分伤害反震给最近敌人；失去击杀回复 | 前向盾牌外观（会错误承诺不存在的前方格挡） |

## 质量门槛

- 任何身体附件必须随真实模型节点运动、落地、转身和攻击；模型节点
  不可用时，该附件不显示，绝不临时挂在世界原点。基础锥体、球体或
  未经前/侧/后近中远景验收的附件不得进入试玩版本。
- 每次命中只触发一次反馈束：形状/动作 + 声音 + 限度内的命中停顿、
  镜头创伤、闪光或碎屑。镜头和粒子不得改写战斗状态。
- 震荡、减速、反震、回血、额外范围都必须有单元测试与调试状态。
- 若某种效果在 844×390 横屏下无法从正常战斗距离读出，优先加强轮廓、
  动作或目标反应，而不是添加文字说明。

## 实施顺序

1. 撕裂爪：验证“身体部件 + 前向攻击 + 抓痕 + 高风险伤害”完整链。
2. 硬壳格挡：验证受击反馈不影响玩家碰撞、转向或输入。
3. 棘尾横扫与压制孢雾：验证多敌人可读性与性能上限。
4. 猎食再生：验证击杀、吸收、回血与生命上限代价的一致性。
