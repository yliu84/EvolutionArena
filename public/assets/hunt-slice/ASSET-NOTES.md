# Gloamwood Hunt Slice prop assets

## `gloamwood-broadleaf-v1.png`

- Purpose: independent foreground broadleaf prop for bottom-center anchoring, y-sort occlusion and trunk collision tests.
- Created: 2026-08-14 with OpenAI ImageGen using the accepted Gloamwood atmosphere map and selected visual master as references.
- Source output: transparent 1254×1254 PNG; project copy downscaled non-destructively to 640×640 for browser use while preserving alpha.
- Included: one complete broadleaf tree with visible trunk, roots, layered canopy and restrained upper-left light.
- Excluded: ground tile, environment background, characters, creatures, UI and effects.

## `gloamwood-conifer-v1.png`

- Purpose: independent foreground conifer prop for bottom-center anchoring, y-sort occlusion and trunk collision tests.
- Created: 2026-08-14 with OpenAI ImageGen using the accepted Gloamwood atmosphere map and selected visual master as references.
- Source output: transparent 1024×1536 PNG; project copy downscaled non-destructively to 426×640 for browser use while preserving alpha.
- Included: one complete conifer with visible trunk base, roots and tiered canopy.
- Excluded: ground tile, environment background, characters, creatures, UI and effects.

Both assets are project-bound prototypes. Their current four placements validate the render/collision pipeline, not final forest density.
