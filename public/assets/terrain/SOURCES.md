# Terrain textures

All albedo maps are from [ambientCG](https://ambientcg.com/), licensed [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

| File | Asset | Use |
| --- | --- | --- |
| `forest.jpg` | [Ground037](https://ambientcg.com/a/Ground037) | woodland moss and soil |
| `dirt.jpg` | [Ground042](https://ambientcg.com/a/Ground042) | leaf litter and bare earth |
| `mud.jpg` | [Ground054](https://ambientcg.com/a/Ground054) | wet banks and river bed |
| `grass.jpg` | [Grass004](https://ambientcg.com/a/Grass004) | meadow splat |
| `bark.jpg` | [Bark007](https://ambientcg.com/a/Bark007) | tree trunks |

Tree canopies stamp Ground037 (`forest.jpg`) as foliage albedo, then shade each leaf mass as a 3/4 globe. They do not use the lawn grass map.

Source packs were 1K JPG color maps, resized to 1024px for the web build. Normal / roughness maps were not included.
